# 3단계 대사 검토표

녹음하기 전에 **문장 틀**만 검토해 주세요. ○ 자리에는 게임마다 나올 수 있는 숫자가 모두 들어가요.
전체 문장은 `docs/음성 목록.md`에 있어요 (모두 1,570개).

- 이미 녹음이 있어서 그대로 쓰는 문장: 155개 (인사, 칭찬, 잠금 화면, 동물 이름 등 1단계와 같은 문장)
- **새로 녹음할 문장: 1,415개**
- 읽는 규칙
  - 개수는 우리말로 읽어요: "다섯 개", "세 마리", "스물세 개"
  - 수 읽기는 숫자 그대로 읽어요: "3 더하기 2는 5야", "27보다 하나 큰 수"

## 3. 바뀐 점

- 장보기는 녹음 수를 줄이려고 물건을 사과 하나로 줄였어요. 화면 그림도 사과만 나와요.
- 1단계에만 쓰던 대사(물웅덩이, 반짝 무늬, 풍선 불기, 선 긋기 길 등)는 목록에서 뺐어요.
  - 그 녹음 파일 102개와 문장이 바뀐 녹음 9개도 지웠어요. git 기록에 남아 있어서 되돌릴 수 있어요.

## 4. 녹음하는 방법 (검토가 끝난 뒤)

1. 터미널에서 `3단계-앱` 폴더로 가요.
2. 키를 환경 변수로 넣고 녹음을 실행해요.
   - 무료 요금제는 1분에 20문장까지라서 1,415문장은 약 75분 걸려요.
   - 중간에 멈춰도 다시 실행하면 이어서 녹음해요.
   - 처음에는 `-- --limit 3`을 붙여 3개만 먼저 들어 봐도 좋아요.
